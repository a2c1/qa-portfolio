# QA Portfolio

Portafolio de pruebas de software de Andrés Colmenares, QA Engineer (ISTQB CTFL). Cada carpeta
es un proyecto independiente con su propio README y su propia forma de ejecutarse.

## Proyectos

| Carpeta | Qué contiene | Stack | Cómo se usa |
| --- | --- | --- | --- |
| [manual-testing](manual-testing/) | Ciclo de pruebas manuales del formulario de [DemoQA](https://demoqa.com/automation-practice-form): requisitos, plan, 40 casos, trazabilidad, bugs y cierre | ISTQB, Markdown, CSV | Documentación; los casos se ejecutan a mano en el navegador |

Los proyectos de automatización se agregan a esta tabla conforme se terminan: API con Postman
y Newman, validación de datos con SQL, UI con Selenium y Playwright, rendimiento con k6 y
generación de casos con IA.

qa-portfolio/
